Deep Inheritance (HTML)

Shows a deep hierarchy of pages. The 2 template base classes provide common markup. And the pages provide specific content:

  • DeepInheritanceBaseTemplate: provides very simple common markup, which is not used as DeepInheritanceSubTemplate overrides it with its own markup.
    • DeepInheritanceSubTemplate: provides a proper HTML page as the common markup for subpages.
      • DeepInheritanceBasePage: adds a label, and allows for child pages to provide markup.
        • DeepInheritanceSubPage: adds a label.
